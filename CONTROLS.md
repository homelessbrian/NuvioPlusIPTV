# 🎮 Remote controls

How to get around Nuvio + IPTV with your TV remote. [Back to the README](README.md)

### In the guide
| Button | Action |
|---|---|
| **OK** on what's on now | Play in the preview · again for full screen |
| **OK** on a later show | Show info · **Remind me** · **Record** |
| **OK** on an earlier show | Play from catch-up |
| **◀** (tap) on what's on now | Open the groups |
| **◀** (hold) | Scroll back through earlier shows (catch-up channels) |
| **▲ / ▼** · **CH+ / CH−** | Channels · page up / down |
| **0–9** | Jump to a channel number |
| **Long-press OK** | Channel menu: favorites, **Remind me**, **Add to Multiview**, **Record**, **Watch from the beginning**, hide, **Manage visibility**, **Reorder**, **Copy**, rename, renumber, **Assign EPG** |
| **Hold Back** or **Play/Pause** | Back to full screen on what's playing |
| **Back** | Back to "now" → the group list → the side menu |

### Full screen
| Button | Action |
|---|---|
| **▲ / ▼**, **CH+ / CH−** | Next / previous channel |
| **OK** | Info panel (catch-up: pause / play) |
| **◀** | Overlay mode (catch-up: skip back) |
| **▶** | Catch-up: skip forward (hold to skip faster) |
| **⏪ / ⏩** | Catch-up and paused live TV: 30 seconds back / forward (hold to go faster) |
| **Long-press OK** or **Menu** | Audio, subtitles, screen size, picture shape, stream info, sleep timer, record, **Add to Multiview**, watch from the beginning, find & stream |
| **Back** | Back to the guide |

### Overlay mode
| Button | Action |
|---|---|
| **▲ / ▼** | Channels |
| **OK** on a channel | Watch it |
| **◀** | The groups (**OK** on a playlist heading folds or unfolds it) |
| **▶** | The channel's schedule · **▶** again for the date picker |
| **Back** | Close the overlay |

### On Demand
| Button | Action |
|---|---|
| **▲ / ▼** in the categories | Browse; each category opens as you highlight it |
| **▶** from the categories | Into the posters (the categories slide away) |
| **◀** from the first column, or **Back** | Categories again |
| **Long-press a poster** | Details, library and watched options |
| **Long-press a category** | Manage visibility · Lock with PIN |

### Sports
| Button | Action |
|---|---|
| **OK** on a game | Game info: channels, score, Remind me, Record |
| **Hold OK** on a game | Watch it in the video window (again: full screen) |
| **◀ / ▶** on the big card | Your next games |
| **▲** from the games | The top bar: My Sports, All Events, 🏆 Tables, your sports (and the day tabs on All Events) |
| **Hold Back** | Full screen on the game in the video window |
| **Back** | The side menu |

### A game's page
| Button | Action |
|---|---|
| **OK** on a channel | Watch it in the video window · again for full screen |
| **▲** to the teams, then **OK** | The team's card |
| **OK** on the Table panel | The whole table, with both teams marked |
| **Back** | Back to the list |

### Tables
| Button | Action |
|---|---|
| **◀ / ▶** on the leagues | Another league's table |
| **▲ / ▼** in the table | Through the teams |
| **OK** on a team | Its card: **Watch now** or **Remind me**, **Follow**, **All their games**, **Game info** |
| **Back** | Closes a team's card · from a game's table, back to the game |

### Recordings
| Button | Action |
|---|---|
| **OK** | Play (or resume) |
| **Long-press OK** | Play from the beginning, stop recording, **Information**, delete |
